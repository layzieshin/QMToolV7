# Nachschärfung v2 – Änderungsübersicht

**Stand:** 2026-08-03

Gegenüber dem ersten Paket wurden folgende Punkte ergänzt oder korrigiert:

- Eventkatalog von einer kurzen Auswahlliste auf 61 v2-Domain-Events erweitert.
- Für jeden fachlichen Workflow-/Statusübergang ist ein spezifisches Event mit Aufgabenrouting vorgesehen.
- Ist-Befund dokumentiert: aktueller EventBus synchron/nicht dauerhaft; Dashboard derzeit zustandsbasiert.
- Bestehende Word- und PDF-Kommentarfunktionen ausdrücklich als zu erhaltender Soll-Bestand aufgenommen.
- Kern-Use-Cases von 30 auf 50 erweitert.
- Separater exzessiver Kandidatenkatalog mit 211 Use Cases erstellt.
- Separater Edge-Case-Katalog mit 96 Fällen erstellt.
- Cursor-Auftrag, Sollmodell, Umbauplan, Entscheidungsmodell und Excel entsprechend aktualisiert.
- Kandidaten- und Edge-Case-Listen sind kein automatischer Umsetzungsscope.
